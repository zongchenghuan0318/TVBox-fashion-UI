# Z影视

Z影视 是一款面向电视的影视聚合客户端，主要用于电视盒子和智能电视，也可以在手机横屏上使用。它本身不提供影片，而是把你配置的多个影视源汇集到一起：搜一次，所有已勾选的源一起查，结果按你设定的源顺序排列，选中就能播放。

> 软件与影片接口完全免费，请勿轻信任何广告。
> 影片资源来自互联网第三方，本软件不存储、不传播任何视频内容。

首次使用请先看 **[《Z影视 使用指南》](./使用指南.md)**。

| 项目 | 说明 |
| --- | --- |
| 当前版本 | v1.5.5 |
| 系统要求 | Android 5.0 及以上 |
| 设备 | 电视盒子、智能电视（主要），手机横屏 |
| 处理器架构 | 仅 armeabi-v7a |
| 应用更新 | 设置中可检查更新，可选启动时自动检查 |

## 功能概览

### 首页
- 默认数据源为「豆瓣推荐」，并固定排在数据源列表第一位。
- 推荐卡片以弧形排列，选中的卡片位于弧顶并放大，左右两侧依次下沉、变暗。
- 背景海报随选中的卡片同步切换。
- 停留 6 秒无操作自动切换到下一张，按键或焦点变化会立即打断并重新计时。
- 首页内容有多级兜底：豆瓣直连失败时依次使用本地缓存、当前数据源的推荐，并可切换到其他可用数据源。
- 点击卡片会以片名直接进入搜索页，挑选可用线路。

### 分类
- 侧边栏分类固定为：电影、电视剧、综艺、动漫、纪录片。
- 「直播」为独立入口，直播源在设置中配置。
- 分类页的卡片同样以片名进入搜索页。

### 搜索
- 一次搜索同时查询所有已勾选的源。
- 结果按搜索源的勾选顺序排列，越靠前的源越优先。
- 默认全选，默认优先级为「文采┃秒播」、「非凡┃影视」，其余源随后。
- 搜索最多等待 15 秒。超时后已返回的结果照常显示；如果有未响应的源，会短暂弹出提示，并显示「重试」按钮。
- 没有任何结果时，会提示「搜索超时，没有找到结果；可重试未响应来源」。

### 收藏与历史
- 收藏和历史以网格展示，支持删除模式。
- 「清空」需要二次确认。

### 播放
- **画面比例**：按一次切换一项，循环顺序为：默认 → 16:9 → 4:3 → 填充 → 原始 → 裁剪。
- **倍速**：按一次切换一档，循环顺序为：1.0 → 1.5 → 2.0 → 3.0 → 0.5 → 1.0。
- **播放控制**：确定键暂停或播放；左右键快进快退，每次 10 秒，按住会加速；上键在有多集时打开选集面板；下键呼出底部控制栏。
- **长按加速**：遥控器上长按确定键，播放中进入 2 倍速，松开恢复。触摸屏上按住画面进入 2 倍速，左右拖动可在 2 倍与 3 倍之间切换，下滑可锁定倍速。
- **屏幕锁定**：锁定后按任意方向键会显示锁图标，按确定键解锁。
- **控件自动隐藏**：控制条约 4 秒无操作后隐藏，底部控制栏约 6 秒后隐藏；按任意键或触摸屏幕可重新显示。
- **自动下一集**：播完一集后会出现 8 秒倒计时，可取消或立即播放下一集。
- **字幕与音轨**：支持视频内嵌字幕、站点字幕，以及本地字幕文件（SRT、VTT、ASS、SSA）。音轨可按语言偏好匹配。
- **续播**：每一集的播放位置会每 5 秒保存一次，退出时也会保存；再次打开同一影片同一线路同一集时，会从上次位置继续。播完的集会清除进度。
- **起播超时**：起播 20 秒内仍未出画面，会提示「播放超时，请检查线路或网络」并给出重试入口，不会自动重试。

### 设置
- **配置地址**：输入后先校验，校验通过才会保存；失败时显示具体原因，并同时显示站点总数和可搜索站点数。
- **配置库与收藏地址**：保存过的地址可直接选择切换。
- **配置地址容灾**：当前地址连不上时，依次尝试配置库中的地址、内置备用地址和默认地址，采用第一个可用的；全部失败则使用本地缓存。
- **直播源地址**：可填写多行 M3U 或 TVBox JSON 格式的直播源，多源合并后去重。
- **播放相关**：播放器、IJK 解码、渲染方式、画面缩放、嗅探 WebView、安全 DNS 等。
- **长辈模式**：放大文字，并延长控件显示时间。
- **局域网网页**：可扫码在手机上打开当前配置，或向电视推送内容（默认端口 9978）。
- **检查更新**：可手动检查，也可在启动时自动检查。

## 常见问题

- **首页或搜索没有结果**：先检查网络。到「设置 → 搜索源管理」确认已勾选可用的源。
- **首页一直转圈或空白**：豆瓣接口可能对当前网络限流，应用会冷却约 5 分钟后再直连。等待几分钟，或更换网络。
- **视频打不开**：换一条线路或换一个源再试。仍然失败可以在设置中更换播放器或 IJK 解码方式。

更多问题请参考 [使用指南](./使用指南.md) 中的 FAQ。

## 技术实现细节

以下内容面向想了解实现的读者。

### 首页
- 卡片由 `HomeCardRecyclerView` 呈现，弧形排布、缩放与透明度随位置变化；切换动画时长 350ms。
- 卡片尺寸由 `home_card_*` 尺寸令牌控制，`values-sw600dp` 提供大屏覆盖。
- 背景海报是 Activity 级独立图层，不随 ViewPager 切换残留；海报经 `SharpenTransformation` 锐化。
- 自动轮播间隔为 `AUTO_SCROLL_DELAY = 6000ms`。
- 豆瓣被风控后进入 5 分钟冷却（`FirstFragment`），冷却期内只使用缓存与兜底数据。冷却时间只保存在内存中，重启应用会清除。

### 搜索
- 搜索任务由 `Future` 管理，页面销毁或重新搜索时取消。
- 结果按搜索源勾选顺序排序，每批返回后重新排序。
- 搜索超时为 15 秒（`SearchActivity`）。超时后取消未完成的请求，并显示重试按钮。
- 默认优先级由 `DefaultConfig.SEARCH_SITE_PRIORITY` 定义。

### 播放
- 播放器基于 IJKPlayer 与 ExoPlayer 封装（`player` 模块），支持 MX、Reex 等第三方播放器接入。
- 续播键由「源 + 影片 + 线路 + 集地址」组成（`PlayActivity.buildEpisodeProgressKey`），保存间隔为 5 秒。
- 起播超时为 20 秒（`playbackStartTimeout`），超时后进入错误重试状态。
- 倍速档位为 `{0.5, 1.0, 1.5, 2.0, 3.0}`（`VodController`）。
- 画面比例循环使用 `VideoView` 的 `SCREEN_SCALE_*` 常量，默认值为 `SCREEN_SCALE_DEFAULT`。
- 遥控器长按确定键 400ms 后触发 2 倍速加速（`BaseController.startKeySpeedBoost`），仅在播放中有效。
- 触摸加速由 `SpeedGestureState` 管理，状态包括 2 倍、3 倍、锁定。
- 字幕解析由 `ExternalSubtitle` 完成，区分 ASS/SSA 与 SRT/VTT 两种格式。
- 控件隐藏时间由 `setDismissTimeout` 设置：普通模式 4 秒，长辈模式 10 秒。底部控制栏为 6 秒或 10 秒。
- 自动下一集倒计时为 8 秒（`AUTO_NEXT_COUNTDOWN_SECONDS`）。

### 配置源
- 配置校验由 `ApiConfig.verifyConfig` 完成：先下载，再解析 JSON，最后统计站点数量。
- 候选顺序为：当前地址、配置库、`DEFAULT_API_SAVED_CONFIGS`、默认地址。试连时读取超时为 7 秒。
- 内置采集源 `DefaultConfig.EXTRA_SITES` 包括非凡、量子、暴风、极速，会排在站点列表最前。
- 直播源支持 `{`、`[`、`#EXTM3U` 开头的内容，每行一个地址；多源合并时按 `LinkedHashSet` 去重。

### 更新
- 主更新源为 Gitee 发行版，备用为 GitHub 发行版（`UpdateClient`）。
- GitHub 下载依次尝试 `gh-proxy.com`、`ghfast.top` 和直连三条线路。
- 清单包含 SHA-256 校验值，下载后必须通过校验才会安装。
- 安装通过系统安装界面完成，不做静默安装。

### 其他
- Glide 4.14.2 用于图片加载；OkGo 3.0.4 与 OkHttp 3.12.1 用于网络请求。
- 数据库为 Room 2.3.0，设置存储使用 Hawk 2.0.1。
- 脚本运行时包括 QuickJS（`wang.harlon.quickjs` 2.4.5）与 Chaquopy Python，内置爬虫包 `tvbox.jar` 由 `DexClassLoader` 加载。
- 局域网服务由 NanoHTTPD 2.3.1 实现，类为 `RemoteServer`，默认端口 9978。

源码结构、包说明与构建方法见 [开发说明](./docs/开发说明.md)。
