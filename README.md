Z影视是一款以电视盒子和智能电视为主要使用场景的 Android 影视聚合客户端，也支持手机横屏使用。它不内置或提供影片内容，而是读取用户配置的影视源，将搜索、详情、播放、收藏和历史整合到一个适合遥控器操作的界面中。

> 软件与影片接口完全免费，请勿轻信任何广告。
> 影片、图片和接口来自互联网第三方；本项目不存储、不上传、不传播任何影视资源。

首次使用建议先阅读 **[《Z影视使用指南》](./使用指南.md)**。

## 下载与安装

### GitHub Release

前往 [Releases 页面](https://github.com/zongchenghuan0318/TVBox-fashion-UI/releases) 下载最新的 `Z.apk`。每个正式版本同时提供：

- `Z.apk`：正式签名安装包。
- `update.json`：应用内更新使用的版本清单。
- `SHA256SUMS.txt`：APK 的 SHA-256 校验值。

当前版本直接下载：[Z.apk v1.7.22](https://github.com/zongchenghuan0318/TVBox-fashion-UI/releases/download/v1.7.22/Z.apk)

### 电视盒子或智能电视

1. 将 APK 复制到 U 盘，或通过局域网传到电视。
2. 在电视文件管理器中打开 `Z.apk`。
3. 如果系统阻止安装未知来源应用，在系统安全设置中允许文件管理器安装应用。
4. 安装完成后打开 Z影视。

### 手机安装

直接打开 APK 安装即可。应用主要按横屏电视界面设计，手机上建议开启自动旋转或手动横屏。

### ADB 安装

适合开发调试或已连接 USB 调试设备的情况：

```powershell
adb devices
adb install -r -d Z.apk
```

应用包名为 `com.studio.osc`。正式包必须使用项目认可的发布签名，不能使用任意调试签名覆盖已安装的正式版本。

## 核心功能

### 1. 启动、缓存与后台预加载

- 启动优先读取与当前配置地址匹配的本地缓存；首页源返回有效数据后，再后台检查配置更新，更新内容供下次启动使用。
- 首页分类和站点推荐按配置源、影视站点分别缓存，先展示已有缓存，再请求新内容。
- 普通 HTTP 首页可以直接获取分类和推荐。首页源需要爬虫时，会等待对应 JAR 准备完成。
- 首页启动遮罩退场、配置就绪后等待 3 秒，自动后台预加载全局爬虫 JAR。提前搜索或播放时，共用同一次加载任务。
- JAR 优先复用本地文件，校验文件结构及配置提供的 MD5；后台下载的 JAR 更新在下次加载时启用。
- 离开首页或切换配置会取消尚未开始的预加载；返回首页后按当前配置重新安排。
- 直播频道与解析列表在首次使用对应功能时处理。

启动遮罩等待配置和首张海报就绪，或完成占位兜底；初始化开始约 12 秒后会超时收起，方便进入设置排查。首次自动选首页时优先探测 HTTP 影视源，6 秒无有效结果后尝试爬虫源，自动探测总等待上限为 12 秒。首次下载、插件初始化及源站响应仍会影响实际等待时间。

### 2. 首页推荐

- 支持豆瓣推荐、站点推荐、观看历史三种首页列表模式，默认使用豆瓣推荐。
- 首页影视数据源可手动选择，也可使用自动选源。
- 提供低压力首页模式，使用静态背景和手动切换，适合性能较弱的设备。
- 首页背景海报跟随当前选中的卡片切换。
- 约 7.5 秒无操作后自动切换下一张卡片。
- 遥控器按键、焦点移动和手动拖动会打断自动轮播，并在操作结束后重新计时。
- 豆瓣请求失败时，会依次使用本地缓存、当前数据源推荐和其他可用数据源进行兜底。
- 选中首页卡片后，可进入对应影片的搜索结果并选择可用线路。

### 3. 十三种首页卡片样式

在 **设置 → 首页卡片样式** 中可以切换：

| 样式 | 视觉特点 |
| --- | --- |
| 星轨环游 | 卡片沿弧线环绕移动，新用户默认样式 |
| 垂直升降 | 卡片上下层叠移动，保留相邻卡片露边 |
| 折扇选片 | 卡片以扇形展开并围绕焦点切换 |
| 桌面抽牌 | 卡片像桌面牌组一样错位叠放 |
| 光闸切片 | 海报以分片切换动画过渡 |
| 胶片走带 | 卡片像胶片一样横向经过 |
| 3D 海报转盘 | 卡片使用横向透视和旋转效果 |
| 穿过海报 | 选中卡片时产生穿透式视觉变化 |
| 平直横移 | 更克制的横向平移样式 |
| 引力抽片 | 海报横向抽出并带有抬升与旋转 |
| 断层错位 | 海报分带错位过渡 |
| 翻板坠落 | 海报翻转并向下退场 |
| 双星换位 | 两张海报相互换位 |

所有首页卡片样式共用首尾循环机制：

- 真实影片列表不会被复制修改。
- 适配器使用虚拟位置映射到真实影片位置。
- 遥控器、自动轮播和手动拖动均可跨过首尾继续切换。
- 手动拖动到虚拟边界后，会自动回到中间等价位置，避免卡片停在列表尽头。
- 少量影片同屏重复的特殊处理目前未单独限制。

项目还提供了一个不影响 Android 设置的交互式选型页：[card-motion-showcase.html](./design/card-motion-showcase.html)。可以先在浏览器中体验动效，再决定是否应用到客户端。

### 4. 四种首页布局

在 **设置 → 首页布局** 中可以切换：

- **经典侧栏**：左侧固定分类栏，适合传统电视导航。
- **Apple TV 顶栏**：分类移动到顶部，内容区域横向铺开。
- **动态抽屉**：默认隐藏侧栏，需要时从左侧滑出。
- **极简沉浸（默认）**：全屏画报式布局，顶部导航按需显示。

动态抽屉布局支持：

- 内容区最左侧按遥控器左键唤起侧栏；
- 遥控器菜单键唤起侧栏；
- 唤起后自动把焦点放到当前首页分类；
- 侧栏打开时按右键进入当前分类内容；
- 再次按菜单键重新聚焦当前分类。

Apple TV 和极简沉浸布局已取消通过屏幕上半区左右滑动切换分类，避免与卡片滑动产生冲突；顶部导航和遥控器导航仍可正常切换分类。

### 5. 分类浏览

分类入口固定为电影、电视剧、综艺、动漫和纪录片，实际分类内容与筛选项由当前首页影视源提供。支持分类筛选，结果按网格展示，选中影片后进入搜索或详情流程。

「直播」是独立入口，直播源需要在设置中配置。

### 6. 多源搜索

- 一次搜索可同时查询所有已勾选的影视源。
- 结果按照搜索源优先级排列。
- 每个源独立返回结果，部分源失败不会阻塞已经返回的结果。
- 首轮搜索响应全部返回，或等待约 45 秒后，进入失败及未响应来源的后台重试阶段；已有结果继续展示。
- 来源重试有次数限制，切换搜索词或退出页面会取消旧请求及待执行的重试。
- 支持文字列表、缩略图两种搜索展示模式，以及搜索历史、热词和输入联想。
- 支持聚合结果中的目录卡片，进入目录后可继续浏览影片，返回时保留原搜索结果和滚动位置。
- 聚盘搜目录使用分类接口；其他插件优先使用详情接口，必要时尝试分类接口，兼容性取决于插件实现。
- 没有结果时会提示检查网络、配置和搜索源状态。

### 7. 详情页

详情页展示影片海报、名称、简介、类型、年份、主演、导演、评分和可播放剧集等信息，具体字段取决于数据源。

当前详情页背景使用高清海报背景：

- 使用更高分辨率加载背景；
- 已移除过强的高斯模糊；
- 保留暗色遮罩，保证详情文字可读；
- 背景随影片详情切换。

### 8. 播放

- 支持系统播放器、IJK 和 Exo，默认使用 Exo；IJK 可选择硬解码或软解码。
- 默认使用 SurfaceView 渲染，也可切换 TextureView。
- Exo 点播支持磁盘缓存，拖动回看可复用已缓存数据；缓存容量按设备可用存储空间调整，并自动淘汰旧数据。
- HLS 点播支持后台预取后续分片，实际效果取决于网络、播放地址和格式。
- Exo 播放失败时可自动回退 IJK，并尽量保留当前播放位置，同一次播放避免反复切换内核。
- 确定键暂停或播放。
- 左右键快进、快退，长按可加速定位。
- 上键打开多集影片的选集面板。
- 下键显示控制栏。
- 遥控器长按确定键可进入临时 2 倍速。
- 播放控制栏会在一段时间无操作后自动隐藏。
- 支持自动播放下一集，并提供倒计时取消。
- 支持视频内嵌字幕、站点字幕和本地字幕文件。
- 支持多音轨选择和语言偏好匹配。音轨与字幕语言可选择自动、中文、英文、日语、韩语、法语、德语或西班牙语。
- 播放进度按来源、影片、线路和剧集保存，退出时也会保存。
- 起播超时后显示重试入口，不会无限自动重试。
- 支持画面比例、0.5× / 1× / 1.5× / 2× / 3× 倍速及渲染方式设置。
- 支持全局片头、片尾跳过时长及其调整步长设置。
- 手机触摸支持进度、亮度和音量手势；长按进入临时倍速，横向拖动调整倍速，下滑可锁定倍速。

### 9. 收藏与历史

- 收藏和播放历史以网格展示。
- 支持删除模式。
- 清空操作需要二次确认。
- 播放历史可用于继续播放。

### 10. 设置与配置容灾

设置页分为播放、首页与搜索、数据与缓存、关于四组，支持遥控器焦点切换和触屏操作。

- **播放**提供播放器、IJK 解码、渲染方式、画面比例、音轨与字幕语言、片头片尾跳过、快进快退步长和字幕开关。
- **首页与搜索**提供首页影视源、推荐模式、低压力首页、四种布局、十三种卡片样式、搜索展示模式和搜索源选择。
- **数据与缓存**提供配置地址、直播源管理、缓存清理和备份恢复。
- **关于与辅助设置**提供手动及自动检查更新、长辈模式、遥控器按键音等选项。

配置地址支持手动输入、本地文件和局域网网页填写，保存前会先下载、解码并校验。可以保存常用地址、查看历史、置顶或取消置顶。

切换配置、首页源或推荐模式后，返回现有首页应用变更。切源前的旧配置和选源回调会失效，减少重复初始化及旧结果覆盖新选择的情况。

### 11. 直播与直播源管理

- 直播使用独立入口，支持 M3U、TVBox JSON 地址与内联内容，多源加载后合并频道并去重。
- 直播源管理支持添加、命名、编辑、启用或停用、上移或下移、删除；每行通过“更多”菜单操作。
- 支持频道分组、数字键选台、遥控器上下换台和多线路选择。
- 直播设置支持画面比例、播放解码、5～30 秒超时换源、显示时间、显示网速、换台反转与跨分类换台。
- 支持带密码的频道分组。多个频道连续超时后暂停自动换台。
- 自定义直播源加载失败时可使用配置中的直播列表兜底，实际频道可用性由源站决定。

### 12. 备份、恢复与缓存清理

在 **设置 → 数据与缓存 → 备份恢复** 中，可备份应用数据库及 Hawk 保存的设置，包括收藏、观看历史等数据。备份保存在设备共享存储的 `tvbox_backup/` 目录，按时间命名，支持从列表恢复或删除。

备份与恢复需要相应存储权限。恢复后会提示重启应用，以重新读取恢复的数据。

设置页提供一键缓存清理，可释放图片缓存和应用缓存等占用；Exo 视频缓存还会按容量策略自动淘汰旧数据。

### 13. 遥控器与辅助功能

- 方向键、确认键和返回键提供提示音，可在设置中关闭；长按重复事件和手机触屏操作按各自逻辑处理。
- 长辈模式增大文字并延长部分控制面板的显示时间。
- 设置和列表界面提供焦点高亮、分组导航及状态反馈。
- 设置页底部标识支持连续点击触发动画彩蛋。
- 手机、平板支持横屏触摸操作，播放页支持手势控制。

### 14. 局域网网页

通过应用显示的二维码或局域网地址，在同一网络的手机、电脑浏览器中打开控制页面。默认端口为 `9978`，可以填写配置地址、发送搜索文字和管理共享存储目录内的文件。

配置地址从网页发送后会填入配置对话框，仍需在电视上完成校验和应用。影片推送依赖配置中的 `push_agent` 站点支持。

### 15. 应用内更新

- 支持设置页手动检查更新，也可启用启动后的自动检查。
- 自动检查安排在首页源返回有效数据后，减少与首页初始加载同时进行的工作。
- 比较 Gitee 与 GitHub 的版本信息，GitHub 下载支持备用线路。
- 安装前校验文件大小、SHA-256、包名、版本号及正式发布签名；安装交给系统安装器处理。

## 遥控器操作

| 按键 | 首页 | 分类 / 搜索 | 播放页 |
| --- | --- | --- | --- |
| 上 / 下 | 切换导航区域或页面 | 移动焦点 | 选集、控制栏 |
| 左 / 右 | 切换卡片或导航项 | 移动焦点 | 快退 / 快进 |
| 确定 | 打开当前项目 | 确认选择 | 播放 / 暂停 |
| 菜单 | 动态抽屉唤起侧栏 | 打开相关操作 | 显示播放操作 |
| 返回 | 返回上一级 | 返回上一级 | 退出控制层或返回 |

不同布局会对左右和上下键做适配。例如动态抽屉布局在内容区最左侧按左键可唤起侧栏，菜单键也可以直接唤起侧栏；极简沉浸布局按上键或菜单键可显示顶部导航。

## 常见问题

### 首页为空或一直加载

先检查网络，再进入设置检查配置地址是否可访问、是否能解析出站点。启动遮罩约 12 秒超时收起后可进入设置。首次使用新配置或新 JAR 仍需下载，后续启动可利用缓存；豆瓣推荐受到限流时会使用缓存或其他推荐数据。

### 搜索没有结果

确认已经勾选搜索源，并检查源的优先级和可用性。多个源同时失败时，通常与配置地址、网络、DNS 或源站限制有关。

### 播放失败

先尝试其他线路或其他来源，再检查播放器和解码器设置。不同源的播放协议、编码和防盗链策略可能不同。

### 遥控器无法进入动态抽屉侧栏

确认当前首页布局是「动态抽屉」，然后按菜单键。也可以在内容区最左侧按左键。侧栏打开后，焦点应自动落到当前分类。

### 更新失败

检查网络和系统安装权限。应用更新会校验包名、版本号、发布签名和 SHA-256；如果 APK 被替换或损坏，更新会被拒绝。

### 正式发布

正式发布前需要：

1. 修改 `app/build.gradle` 中的 `versionCode` 和 `versionName`；
2. 新建对应的 `docs/releases/<version>.md`；
3. 确认工作区干净；
4. 确认正式签名配置有效；
5. 确认 `GITHUB_TOKEN` 或 Git Credential Manager 已配置；
6. 使用 JDK 11 执行发布脚本。

```powershell
$env:JAVA_HOME = 'C:\Program Files\Microsoft\jdk-11.0.16.101-hotspot'
.\tools\publish-github.ps1
```

发布脚本会自动完成：

- Release APK 构建；
- 包名、版本号和签名校验；
- 生成 `Z.apk`、`update.json` 和 `SHA256SUMS.txt`；
- 更新仓库内的 `release/update.json`；
- 推送 `main` 分支；
- 创建版本标签和 GitHub Release；
- 上传 Release 附件；
- 校验远程分支、标签和附件。

不要把 `release-signing.properties`、密钥文件、访问令牌或其他凭据提交到仓库。

## 技术实现概览

- Android 应用包名：`com.studio.osc`。
- 首页由 `HomeActivity`、`FirstFragment` 和 `HomeCardRecyclerView` 协作完成。
- 首页卡片样式集中在 `HomeCardMotion`，真实数据与虚拟循环位置由 `HomeHotVodAdapter` 管理。
- 首页卡片使用虚拟位置块实现首尾循环，不复制真实影片对象。
- 动态抽屉、Apple TV 顶栏、极简沉浸等布局由 `HomeActivity` 统一处理。
- 搜索任务支持超时、取消和分批结果排序。
- 图片加载使用 Glide，数据持久化使用 Room，轻量设置使用 Hawk。
- 播放器位于 `player` 模块，并由播放页控制器统一处理遥控器、触摸、字幕、音轨和续播。
- 局域网网页服务使用 NanoHTTPD，默认端口为 `9978`。
- 应用更新清单包含版本号、下载地址、文件大小和 SHA-256，安装前会校验包名、版本和签名。
