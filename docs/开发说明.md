# Z影视 开发说明

面向开发者的源码结构、技术栈与构建说明。用户向的功能说明见 [README](../README.md)，用户操作手册见 [使用指南](../使用指南.md)。

## 工程结构

Gradle 多模块工程，`rootProject.name = "MoviePlayer"`，包含两个模块：

| 模块 | 说明 |
| --- | --- |
| `app` | 主应用，`applicationId com.studio.osc` |
| `player` | 播放器内核与框架（IJKPlayer、ExoPlayer 封装） |

```
tvbox_source/
├── app/                        主应用模块
├── player/                     播放器模块
├── docs/                       规格、任务、发布与播放器说明
├── tools/tests/                本地 JVM 回归测试脚本
├── gradle/                     Gradle Wrapper
├── build.gradle / settings.gradle
├── site.json                   内置站点配置示例
├── release/update.json         在线更新清单
└── README.md / README.en.md / 使用指南.md
```

```
app/
├── libs/

    ├── assets/

    │   ├── js/lib/             JS 爬虫引擎与依赖（drpy2、cheerio、crypto-js、pako、jinja 等）
    │   ├── parse.html          内置解析页
    │   └── site.json / readme.json
    ├── python/                 Chaquopy 爬虫运行时（app.py、runner.py、trigger.py、base/）
    ├── java/com/github/
    │   ├── tvbox/osc/          主体代码，见下表
    │   ├── catvod/             爬虫加载与执行（JarLoader、crawler、utils）

    │   └── okhttp3/dnsoverhttps/  安全 DNS（DoH）
    └── res/                    layout 61 个、drawable 141 个，另有 values-sw600dp 大屏覆盖
```

## 技术栈

| 项 | 版本或说明 |
| --- | --- |
| 语言 | Java 8 |
| 编译 SDK | `compileSdkVersion 30`，`buildToolsVersion 30.0.3` |
| 运行兼容 | `minSdk 21` / `targetSdk 28`，`abiFilters armeabi-v7a`，开启 multiDex |
| 数据库 | Room 2.3.0（schema 输出到 `app/schemas`） |
| 偏好存储 | Hawk 2.0.1，Gson 2.8.7 |
| 网络 | OkGo 3.0.4、OkHttp 3.12.1、DoH（dnsoverhttps） |
| 图片 | Glide 4.14.2（含 recyclerview-integration） |
| UI | BaseRecyclerViewAdapterHelper 2.9.45、LoadSir 1.3.8、AutoSize 1.2.1、tv-recyclerview 3.0.0 |
| 事件 | EventBus 3.2.0 |
| 脚本运行时 | QuickJS（`wang.harlon.quickjs:wrapper-android` 2.4.5）；Chaquopy Python 爬虫运行时，pip 依赖包含 requests、beautifulsoup4、lxml 等 |
| 本地服务 | NanoHTTPD 2.3.1 |
| 二维码 | ZXing core 3.4.1 |

## 构建

```bash
# 调试包
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/Z影视.apk

# 正式包
./gradlew :app:assembleRelease
```

构建注意事项：

- `app/build.gradle` 的 `python { buildPython ... }` 硬编码了本机路径 `E:/code-tools/TraeREA/Python38/tools/python.exe`。在其他机器上构建前需要改成本地 Python 3.8 的路径，或者去掉该配置。
- Chaquopy 的 Android 原生轮子只从 `chaquo.com/pypi-7.0` 获取，`pip {}` 块不能配置 `indexUrl` 镜像，否则 ABI 轮子解析会失败。
- 依赖已配置国内 Maven 镜像，Gradle 发行版使用腾讯云镜像。
- `app/build.gradle` 中 `signingConfigs` 指向仓库内 `.signing/` 下的 keystore 与 `release-signing.properties`，发布前确认这些文件的使用权限。

本地 JVM 回归测试见 `tools/tests/README.md`，包括 `run-update.ps1`（更新逻辑）、`run-controller-ticker.ps1`（控制条进度刷新）、`run-speed-gesture.ps1`（触摸加速状态）。
