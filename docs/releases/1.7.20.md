# 1.7.20

- 调整电视端设置页返回流程。切换配置地址、首页源或推荐模式后，回到现有首页刷新，减少重复启动和配置重载。
- 切源后使旧配置下载、首页选源及页面回调失效，避免旧结果覆盖新选择；读取源列表时同步配置替换操作。
- 启动遮罩增加 12 秒超时退场，配置或海报加载较慢时仍可进入设置。
- 全局爬虫 JAR 改为首次使用爬虫源或 JAR 解析时加载，并发请求共用同一次加载。HTTP、JS、Python 源可先加载首页。
- 自动首页选源优先探测 HTTP 接口，6 秒无有效结果后尝试爬虫源，自动探测总等待上限为 12 秒。

版本 1.7.20（versionCode 219）。20 项回归测试通过。电视上的切源退出问题和实际启动效果仍待真机验证。
