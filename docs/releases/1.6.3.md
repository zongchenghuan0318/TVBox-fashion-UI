# 1.6.3

## 更新内容

- 点播配置默认置顶：启动时最先尝试置顶的配置地址（默认 https://ysc.tengxuntaobao.win/），配置库中置顶项排在第一位并显示📌，支持手动置顶/取消置顶。
- 搜索源默认置顶：「💥粉猪┃秒播💥」排在搜索顺序第一位并自动启用；已保存过搜索顺序的用户只调整这一项，其它顺序保持不变。
- 搜索源管理新增「选择排在第一位的源」，可把任意源设为第一位。
- 配置库（点播源管理）优化：正在使用的配置不能删除；删除前需要确认；每行可直接置顶。

## 安装包

- 版本：1.6.3（versionCode 192）
- 文件：Z.apk（armeabi-v7a，Android 5.0+）
