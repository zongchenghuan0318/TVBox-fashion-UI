# 1.5.7

## 更新内容

- 设置页改为左侧分组导航（播放 / 首页与搜索 / 数据与缓存 / 关于），开关改为胶囊样式，颜色与首页统一。
- 直播源管理每行只保留一个“更多”入口，启用、排序、编辑、删除都在弹窗中完成。
- 备份还原成功后可直接重启应用；打开备份列表不再自动删除旧备份。
- 播放页：续播提示改为“继续播放 / 从头开始”两个按钮，默认保留续播进度；播放失败时可直接重试或选集；移除横竖屏切换按钮。
- 详情页：空态与超时页面可直接“换源搜索”；标题返回控件可用遥控器选中；每个线路记住上次查看的分段；排序按钮文字改为“倒序 / 正序”。
- 搜索页：点击搜索后焦点交给首批结果；热词接口失败时使用内置词条；清空历史前需要确认；历史词长按删除有操作提示。
- 首页：抽屉布局的拉手可以用遥控器确认键展开；切换布局后焦点交给新布局入口；顶栏图标聚焦时显示功能名称；加载遮罩不再占用焦点。
- 点播配置源：每个地址连接失败时最多尝试 3 次，全部失败才切换到下一个；启动时单次校验超时 4 秒。
- 长辈模式焦点环改为白色，减少布局刷新时的遍历开销。
- 播放器菜单、选择弹窗统一使用同一套弹窗组件。

## 安装包

- 文件：Z.apk（armeabi-v7a，Android 5.0+）
