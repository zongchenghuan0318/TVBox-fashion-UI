播放稳定性与首页视觉改版：

- 蓄水双阈值，终结“播一秒卡一秒”：首播起播门槛从 1.5 秒收紧到 1.0 秒，正常网络下几乎瞬时出画；一旦触发二次缓冲，Exo 要求蓄满 4.5 秒、IJK 要求蓄满 4.0 秒才放行，切断网络轻微波动导致的反复卡顿循环。
- 内存按机器分级，老电视不再闪退：Exo 缓冲上限不再固定 192MB，改为跟随可用堆内存——极老设备 48MB、普通老盒子 80MB、主流电视 144MB、旗舰 224MB；IJK 同步降级为 32MB / 64MB 分档；回退保留在低内存设备自动缩到 30 秒。
- 解码器自动降级：老电视硬解遇到高规格编码报错时，自动回退到兼容硬件或软件解码，不再黑屏卡死。
- 磁盘缓存按剩余空间伸缩：不再固定占 512MB，系统空间始终预留约 600MB；闪存紧张时压缩到 128~256MB，空间宽裕时才放宽到 1.8GB。
- HLS 切片缓存抗 Token 刷新：自动剥离切片地址里的动态鉴权参数，片源换 token 后本地已缓存内容依然命中，回看不再重新下载。
- 拉流通道提速：Exo 侧解除单域名并发限制（每域名 16 路、总 64 路），连接/读取超时放宽到 15s/20s；IJK 侧 TCP 接收缓冲从默认 32KB 放大到 1MB，开启 HTTP 连接复用，流探测分析时间缩短到 1.5 秒。
- 播放出错立即重试：不再要求“刚开始播放”才触发，播放中途出错同样直接进入重试流程。
- 海报滑动不再白闪：只有图片地址为空时才重置占位图，正常加载过程中不再清空已有画面。
- 首页侧边栏视觉改版：去掉青蓝霓虹与发光描边，改为中性烟熏黑玻璃——左侧稍实保证文字可读，右侧轻透让海报透出，焦点态为白色磨砂高光胶囊。
- 首页其他细节：分类条目改为白色磨砂渐变胶囊；移除品牌标题下的强调短横；日期颜色调淡；线路过滤图标跟随侧栏配色。

验证情况：发布构建通过签名校验，并解包确认新代码已进入 APK；缓冲手感、老设备内存表现与首页观感需在设备上实测。
