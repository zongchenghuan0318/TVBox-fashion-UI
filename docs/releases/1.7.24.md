# 1.7.24

- 点播配置切换增加首页准备阶段：在设置页解析新配置、选择首页站点并获取推荐列表，准备成功后再应用。
- 首页准备失败或超过 35 秒时保留原配置，显示失败或超时提示，方便重试。
- 返回首页复用已准备的配置与推荐数据，减少重复解析和等待；豆瓣、历史模式已有内容保留。
- 修复配置解析失败后仍标记成功的问题，失败时恢复原站点、解析器与爬虫引用。
- 推荐获取失败时保留已有卡片；预加载请求与当前首页请求分开标记，减少互相取消的影响。

说明：预加载的是推荐列表，分类和海报图片仍可能在返回首页后继续加载。连续切源及电视端效果尚待实机验证。
