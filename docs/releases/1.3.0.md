优化顶栏对比度与视觉层次，清理第三方上报，启用本地数据备份与还原，发布 1.3.0

- 顶栏视觉重构：新增柔和微透烟熏保护层（自顶向下自然渐隐），彻底解决亮色海报背景下文字/图标辨识度不足的问题，同时保持 Apple TV 通透质感，不厚重、不艳丽。
- 分类胶囊与动作按钮：重构为中性深色烟熏微透磨砂底托与精致微光边缘，并增加标题文字微投影，在任何复杂背景下均保持锐利可读。
- 顶栏遥控落焦反馈：焦点态胶囊增强高对比微白外发光描边与高光提亮，光标位置一目了然。
- 安全与隐私保护：彻底移除播放结果与搜索关键词向第三方 IP 的后台上报逻辑，关停失效的热词接口，保护用户隐私与系统资源。
- 盘活备份功能：设置页原「分享给好友」正式升级为「数据备份与还原」，支持将配置、收藏和历史记录一键备份到本地存储并随时恢复。
- 纯净体验：全面洗净界面与内置资源中遗留的开发者名字、联系电话与群信息，免责与使用声明规范化。
- 版本号升级至 1.3.0 (versionCode 159)。
