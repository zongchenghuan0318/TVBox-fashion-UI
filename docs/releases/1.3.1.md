- 移除失效的全局初始化请求，避免进入配置、搜索、详情或播放流程时触发无效后台请求。
- 移除首页无响应的“分享”快捷入口。
- 修复首页数据源弹窗反复打开时重复添加“自动选择”的问题。
- 移除已废弃的解析 WebView 选项、开机自启组件和无引用的旧布局/资源。
- 删除未使用的 FileDownloader 依赖。
- 更新设置页名称及无搜索源提示，移除对已删除配置资源的文档引用。
- 更新检查会比较 Gitee 与 GitHub 的版本，确保 GitHub 有较新版本时仍能提示升级。
- 版本号升级至 1.3.1 (versionCode 160)。
