修复 1.1.19 及更早版本无法检查到更新。

- 上一版把 GitHub 附件里的更新清单主地址改写成了 Gitee，而 1.1.19 及更早的客户端只接受 GitHub 主地址，会直接判定清单格式错误，导致更新检查失败。
- 现在同一版本发布两份清单：GitHub 附件里的清单只写 GitHub 地址，Gitee 仓库与 Gitee 附件仍以 Gitee 地址为主地址、GitHub 地址为备用。
- 客户端接受任意顺序的主地址与备用地址，Gitee 地址直连一次，GitHub 地址自动展开 gh-proxy、ghfast、直连三条线路。
- 更新清单带 UTF-8 BOM 时也能正常解析。
