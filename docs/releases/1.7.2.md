# 1.7.2

## 更新内容

- 修复应用内远程更新在安装包校验失败后重复切换下载线路的问题。
- 包名、版本号或签名不匹配时立即显示明确错误，不再下载完成后反复回到 0%。
- 网络、文件大小或 SHA-256 校验异常仍会自动尝试备用下载线路。
- 补充更新器测试，覆盖签名校验失败和线路回退场景。

## 重要说明

Debug 包和正式 Release 包使用不同签名。通过源码构建的 Debug 包不能直接覆盖安装正式包；测试更新功能时，请先卸载 Debug 包，再安装正式 Release 包。

## 安装包

- 版本：1.7.2（versionCode 201）
- 文件：Z.apk（armeabi-v7a，Android 5.0+）
