# 在线更新与本机发布

首个支持版本是 1.1.3（versionCode 113）。旧版须先手动覆盖安装一次，之后可在设置中点击“检查更新”。1.1.7 起每次启动首页就绪后自动检查一次并直接提示；失败时不干扰使用。1.1.20 起更新源改为 **Gitee 优先、GitHub 备用**。

## 本机准备

保持原有 JDK 11、Android SDK 和 Python 构建环境。将当前 `C:/Users/zch/.android/debug.keystore` 复制到被 Git 忽略的 `.signing/current.keystore`，另保留备份；不要重新生成密钥。当前环境已经配置。

本地 `release-signing.properties`（被 Git 忽略）包含 `storeFile`、`storePassword`、`keyAlias`、`keyPassword`。路径相对仓库根目录。发布任务将验证证书 SHA-256 必须是 `195cc65bd18f8e04184423ad84306a9ed9582f4f0be5cf7d26b19371e4bcba62`，缺失或不符就停止。release 构建沿用原证书，关闭应用调试功能；签名文件和凭据不得提交。

## 预览与发布

在仓库根目录执行（PowerShell 5.1 及以上）：

```powershell
./tools/publish-release.ps1 -NotesFile docs/releases/1.1.20.md -PrepareOnly
```

此命令只在本地构建，生成 `dist/v1.1.20/Z.apk`、`update.json`、`SHA256SUMS.txt`，并刷新仓库内的 `release/update.json`，允许工作区有尚未提交的代码。核对 APK 版本、证书和说明后进行实机覆盖升级测试；`release/update.json` 需要与代码一起提交。

发布时，先提交并推送本次发布的代码（含 `release/update.json`），确保工作区干净且 HEAD 与 `origin/main` 一致，同时推送到 Gitee。在本机配置两个环境变量：

- `GITHUB_TOKEN`：仅限该仓库 Contents 读写权限。
- `GITEE_TOKEN`：Gitee 私人令牌，勾选 `projects` 权限。

然后执行：

```powershell
./tools/publish-release.ps1 -NotesFile docs/releases/1.1.20.md
```

脚本直接连接两端 API，不通过公共代理发送凭据。它先创建 Gitee 发行版 `v版本号` 并上传 `Z.apk`、`update.json`、`SHA256SUMS.txt`，核对文件名与大小；再创建 GitHub 草稿，核对三个附件的 SHA-256 和大小，最后发布并设为 Latest。Gitee 附件地址形如 `https://gitee.com/the-eternal-cycle/TVBox-fashion-UI/releases/download/v版本号/Z.apk`。

任一步失败立即停止；Gitee 发行版已经创建时不会自动删除，检查后手动删除再重试。已发布版本和已有标签不覆盖。旧的 `share` 发布页不变。

后续发布递增 `app/build.gradle` 的 versionCode，并同步修改 versionName、添加对应更新说明。脚本从实际 APK 读取版本与包名，版本号不能低于已有正式发布。代码推送不会自动触发发布。

## 协议与客户端行为

客户端首先读取 Gitee 仓库内的清单：`https://gitee.com/the-eternal-cycle/TVBox-fashion-UI/raw/main/release/update.json`，失败后再依次尝试 `gh-proxy.com`、`ghfast.top`、GitHub 直连的 `releases/latest/download/update.json`。

清单为七字段 JSON：`versionCode`（整数）、`versionName`、`changelog`、`apkUrl`、`apkUrlFallback`、`sha256`、`size`（字节数）。`apkUrl` 必须是 Gitee 上对应版本的 `/releases/download/v版本/Z.apk`；`apkUrlFallback` 必须是 GitHub 上同一版本的同类地址。1.1.19 及更早的清单只有 GitHub 地址，没有 `apkUrlFallback`，客户端仍然接受。

安装包下载先走 `apkUrl`（Gitee），失败后按 gh-proxy.com、ghfast.top、GitHub 直连依次尝试 `apkUrlFallback`。元数据每线路总超时 8 秒；下载连接超时 10 秒、读超时 20 秒。取消后不切线路，失败或取消清理临时文件；不支持断点续传或后台持续下载。

安装包大小、SHA-256、包名、版本和现有签名都通过验证后才调用系统安装器。Android 8 及以上按需开启安装授权；用户可拒绝安装。浏览器入口属于手动下载，应用无法替浏览器校验其下载文件。

## 验收

自动测试覆盖版本判断、无效更新信息、线路回退、HTML 响应、下载截断与校验失败、取消清理。真实电视仍需验证遥控器焦点和长说明滚动、授权返回、拒绝安装，以及从现有安装覆盖升级后直播源、收藏和历史保留。

公共加速服务的连通性和速度随网络变化，不承诺持续可用。Gitee 清单或附件暂时不可用时，客户端会自动回落到 GitHub。
